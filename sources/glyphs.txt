# ─────────────────────────────────────────────────────────────────────
#  RUNION NEO — glyph source
# ─────────────────────────────────────────────────────────────────────
#  The whole font lives on ONE grid of 3 × 7 points:
#
#        x:  0   1   2
#   y=6      ·   ·   ·     top
#   y=5      ·   ·   ·
#   y=4      ·   ·   ·
#   y=3      ·   ·   ·     middle
#   y=2      ·   ·   ·
#   y=1      ·   ·   ·
#   y=0      ·   ·   ·     baseline
#
#  point    = "xy"            e.g. 06 = top-left, 20 = bottom-right
#  stroke   = points joined by "-" (a polyline, corners are mitred). Any dot may join
#             any other dot: neighbours (05-16) or across the grid (00-16, 06-20).
#             A line may cross another between dots: A's bars run through its legs.
#             first == last  → closed shape
#             a lone point   → a dot
#  RULE     : every Latin letter and digit must touch x=0 AND x=2.
#  CASE     : unicase. a lowercase letter is the plain Latin form; its CAPITAL is the
#             same letter with a rune accent: the rune's extra stroke (A takes ansuz's
#             second arm, M takes mannaz's cross), the rune's pointed bowls (B P R), or
#             the stung dot medieval carvers used to derive one letter from another.
#  RUNES    : the Runic block only (U+16A0…). They are never mapped to Latin letters.
#  MARKS    : accents live outside the letter — two attic rows above (y = 7, 8) and
#             two cellar rows below (y = a, b  →  -1, -2). Every glyph fills the same
#             box, so one mark position fits them all; accented letters (é ñ š ő …)
#             are never drawn: the build composes them from Unicode, letter + mark.
#  GROUPS   : a "# ── title ──" line starts a group in the playground's glyph table.
#
#  line format:   name | characters | strokes
#  characters :   space separated · U+XXXX allowed for awkward characters
#                 "ᚨ+U+030A" = a sequence the font draws as one glyph (OpenType ccmp)
#                 "~ᛊ"       = alternate for ᛊ, shown when the reader turns on ss01
#  strokes    :   "=name" reuses the strokes of a glyph defined above
# ─────────────────────────────────────────────────────────────────────
